三、數值決定蛇身長度

Value 是頭上的數值。
Score 是累計分數。
Level 是關卡。

蛇身長度只由 Value 決定，不由 Score、擊殺數或關卡決定。

玩家與普通 AI 使用同一條長度曲線。先採以下可調預設：

L(V) = clamp(36 + 24 × sqrt(V), 60, 720)

單位是遊戲世界像素，L 表示頭部中心到尾端的路徑長度。先驗證 V 為有限正數；不合法資料安全回退，不產生 NaN。

參考長度約為：

Value 5：90px
Value 10：112px
Value 50：206px
Value 100：276px
Value 200：375px
Value 400：516px
Value 500：573px
高數值最多：720px

這是初版曲線，不是既有規格。集中在設定檔，不要散落硬編碼。最大長度只限制蛇身，不限制玩家數值繼續增加。

渲染可採約 18px 取樣間距，最多約 40 節，最後三節自然收尖。節數只是繪圖手段，不是數值本身。需要每增加數值就能平滑調整長度，而不是等固定擊殺次數才增加一節。

以移動距離儲存和取樣軌跡，避免使用每幀固定紀錄一次的方式造成 30fps 與 60fps 蛇身長度不同。

加速時不得節點散開。
轉彎不得斷裂。
新增尾段從尾端平滑延長，不得從蛇頭跳出。

戰前選擇 5／7／10、吞食加值、幸運轉盤加值、重玩與換關，都必須經同一個長度更新入口。轉盤後蛇身應變長，不能再沿用「轉盤永不改變身體節數」的舊斷言。

受傷仍依原規則扣愛心，但不再額外永久剪短蛇身，因為數值沒有下降。可以做短暫壓縮或閃爍動畫，結束後長度仍由 Value 決定。

將繪圖節數與轉向控制分開，不能因畫得更細或蛇身變長，就偷偷加重轉向懲罰、降低移動速度。保留既有操控感與既有轉向懲罰上限。

出生、teleport、重開場景時，安全初始化軌跡。不得把全部尾段疊在頭上形成碰撞團；尚未展開或不可見的部分不得成為隱形障礙。只有有效、可見路徑參與身體碰撞。

本次新長度系統套用玩家與普通 AI。
Boss100～400 與 UltimateBoss500 保留既有設計，不額外加長身或新攻擊。


四、身體／尾巴反彈規則

加入兩種互動：

玩家頭碰普通 AI 身體會彈開。
普通 AI 頭碰玩家身體也會彈開。

自己的頭不與自己的身體碰撞。本版不增加 AI 與 AI 互撞，也不把 Boss 納入新尾巴反彈系統。

頭對頭保留嚴格比較：

自己 Value > 對方才可吃。
相等不可吃。
較大或相等對手的頭部傷害依原規則。

碰身體則不論大小都只是彈開，不直接吃掉對方。

反彈本身不扣愛心、不扣數值、不扣分、不剪尾巴、不產生掉落。

初版短暫反彈約 150ms，同一移動角色的身體碰撞冷卻約 450ms；參數集中設定。反彈方向由接觸位置決定，有可見位移且很快恢復操控，不把玩家甩出畫面。

處理穿入分離與接觸冷卻：
持續碰在一起不能每幀重彈。
向量長度為零、同時碰多節、靠牆碰撞，也不能 NaN、震盪或卡死。

同幀接觸採確定順序：

先判定有效頭對頭吞食／傷害，再處理仍存活蛇的身體接觸。
已被吞食蛇的身體不再反彈玩家。
每個角色每幀最多處理一次身體反彈。
頭頸交界設合理安全區，避免可吃的蛇頭被自身前段身體判定擋住。

不要直接把尾巴反彈實作成 takeDamage(0)。尾巴接觸冷卻與受傷無敵要分開，不能意外取得 Boss 傷害免疫。

反彈要在真實遊戲迴圈中保留下來，不能剛設定速度，立即被 PlayerSnake.update、AI update 或磁力覆蓋。協調運動狀態與力量套用順序。

磁鐵拉近目標造成接觸後，短暫避免同一接觸對象被立刻再吸回去，不得出現吸入／彈出無限循環。

磁鐵仍只吸較小普通敵人與掉落圈，不吸相等、較大敵人或 Boss。

建議採頭部圓形對蛇身路徑膠囊的偵測，配合空間分區。高速跨過身體時要做掃掠／子步進等防穿透處理。

不要替每一節建立獨立剛體。
低畫質與高畫質的碰撞規則必須相同。


五、吃頭後整條化圈，且獎勵不重算

有效吞食普通 AI 頭部後，先保留該蛇可見路徑與位置，再移除其頭、身體碰撞及 AI 更新。

視覺：

頭被吞掉。
身體沿原路徑快速依序亮起。
每一節化成發光圓圈。
約 0.25～0.45 秒完成。

不能只在蛇頭位置噴粒子，也不能在動畫未出現前全部自動收走，導致孩子看不到化圈。

轉化中的圈先不可收集；短動畫結束後才成為可收集物件。磁鐵可吸走它們。

每隻蛇的死亡事件只能執行一次。
清場、換關、一般 destroy 不得誤生戰利品。

避免長蛇造成無限制獎勵膨脹，採本版新規則：

每隻普通 AI 的身體掉落總池固定為：
50 分
10 點加速能量
0 Value

分配到該蛇實際產生的 N 個圈。用整數分配並保證總和守恆，不能每一圈又給完整總池。

原本蛇頭吞食給的 Value、連擊分數與吞食加速恢復仍照舊。
Boss 獎勵照舊。
身體掉落不再次給敵蛇 Value。

完整收集且未受能量上限截斷時，掉落總收益必須正好 50 分／10 能量；能量仍不得超過 100。

過期、被容量政策移除的圈不自動補發獎勵，也不得重複給分。

掉落壽命維持 11 秒。本版為支援長蛇，活躍可收集圈上限由 80 調為 160，使用物件池與明確的最舊先移除策略；特效亦有上限。

這是本次允許的例外，須做滿載效能測試，不可無限增加。
