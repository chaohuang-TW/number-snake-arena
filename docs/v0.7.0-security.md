本候選沿用既有相依版本，沒有執行 `npm audit fix --force` 或整批升級。`npm run test` 使用 `vitest run`，沒有啟用Vitest UI或對外API；本機試玩與驗收伺服器綁定 `127.0.0.1`，交付以已建置的靜態preview為主。這些做法限制目前使用情境，**不代表漏洞已修復**，也不應把開發伺服器公開到網路。

正式發布前應另外安排相容性升級與完整回歸。這是候選版已知待處理事項；本次保留lockfile重現性及使用者明確的升級界線。
