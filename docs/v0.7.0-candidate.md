以上是已實作內容，最終PASS須讀凍結提交後的外部驗證結果，不從這份說明推定。

兩項初版假設可在 `src/config/gameBalance.ts` 調整：尾巴包含蛇頭後方身體與尾端；長度使用 `clamp(36+24√Value,60,720)` 世界像素，不是一點一節。Score及Level不決定長度。渲染18px間距／最多40節，4px距離紀錄，不依frame數決定長度。最大長度不限制Value加值。

頭對頭、四關、解鎖、愛心獎勵、220／340速度、磁力260px／8秒／20秒、世界2400×1600、Boss100–400與終極500攻擊及幸運轉盤獎項沿用。規格內替換詳列 [測試移轉](v0.7.0-test-migration.md)。本次並修正重玩事件清理、過關解鎖訊息、存檔拒絕回退、轉盤一次點擊及終局畫面座標；沒有新增關卡、後端或付費內容。

畫面由原先簡單圓形節點改為高光短蛇、六種蛇頭輪廓、三節收尖尾端、威脅外框／圖形、獨立化圈動畫及四種層次背景。生命與數值優先、固定鏡頭zoom1、主要按鈕≥48CSSpx、safe-area與依觸控能力顯示搖桿／技能按鈕。減少動態與低特效只改裝飾；圈浮動使用獨立視覺座標，皇冠脈衝避開數字。

本機多貼圖場景曾重現旋轉蛇身被切成碎片：原始貼圖完整，重建Image仍會發生，診斷用固定圓形身體角度則恢復。候選版因此固定身體光線方向、以32個預畫方向的尾巴貼圖取代即時旋轉；保留尾巴幾何長度與收尖寬度。普通AI身體的視覺貼圖由24增至30px，使收尖節點在18px取樣間距仍相接；頭部半徑、尾巴貼圖、物理與路徑長度不變。這是針對實際渲染批次與視覺連接問題的外觀處理，沒有更新相依版本；新凍結版本的像素回歸與最終截圖結果待驗證。

驗收可以設定初始數值、位置、路徑與獎項；最後吞食、傷害及通關由真實update判定，按鈕使用一次原生click／tap。這證明可操作及規則成立，不代表每個測試數值都從Value5自然累積。另有實際鍵盤／觸控移動、追逐捕捉、場內生態加值、暫停、重載與重玩。正常網址不提供debug修改介面。

同一台電腦的本機試玩與測試指令見 [README](../README.md)。已建置preview使用 `npm run preview -- --host 127.0.0.1 --port 3022 --strictPort`，網址 `http://127.0.0.1:3022/number-snake-arena/`；版本、提交及建置時間可由唯讀 `window.__NUMBER_SNAKE_BUILD__` 辨識。這不是公開預覽服務。
