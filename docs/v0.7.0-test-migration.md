# v0.7.0 候選版測試移轉清單

比對來源是基線 `a291da63f584f350002cb09edf63220ba0c166b8` 的 `tests/e2e/run-e2e.cjs`，以及目前 `tests/e2e/*.spec.cjs` 和單元測試。基線原始 E2E 在本次重跑因 `ReferenceError: API is not defined`、exit 1 中止；前任報告的 PASS 不作為本次驗證證據。

目前前置整合 `preflight.log` 的實際結果為 **86 passed／3 failed／1 skipped，exit 1**；失敗為傷害無敵時間、觸控加速恢復與普通AI追捕案例。這是初步結果，最終凍結候選版的完整驗證尚待完成。

此表記錄**斷言所在位置與覆蓋範圍**，不是執行結果。測試名稱列有某個字母，不等於保留了該舊案例的每個斷言。表內「已對應」仍須以凍結候選版的完整 log／退出碼確認 PASS；「部分」列出尚未證明內容；`NOT RUN` 表示該項尚無等價實測，不能因其他案例通過而推定通過。CI、正式站、WebKit、實體手機與 iPad 的結果需分開記錄。

## 本次新增與驗證界線

- 長度非法輸入、30／60／144fps、加速／轉彎、尾端延伸、teleport及靜止容量：`snakePath`、`snakeEntities`；AR2補實際遊戲。
- 零接觸法線、冷卻與去重、牆邊分離、自己的身體／AI彼此／Boss排除：`bodyCollision`；AR3–5與ST3補實際迴圈。
- 高低特效的掉落實際位置／磁力邊界、六種頭型半徑20／18、無敵與同幀活尾反彈、終極場指定造型：PX1–5。
- 圈250–450ms轉化期間不可收集／磁吸、整數50／10／0、100能量上限、expiry與回收：`orbs`、`orbLifecycle`、AR6、ST2。
- 舊造型存檔、壞JSON、未知ID、儲存拒絕與獨立外觀偏好：`cosmetics`、`visualPreferences`、CO1–3。CO3名稱含「failed storage」但只驗壞存檔；LV6才是真正由Storage prototype拒絕偏好／造型讀寫的瀏覽器案例，正常UI與吞食仍可用，且還原後進度／舊造型存檔保持。PX8另讓全部localStorage getItem／setItem拒絕，真實頭接觸死亡後仍可一次playAgain到Prep且零pageerror；全面拒絕時既有進度保存的獨立比較未測，不能推定成功寫入。
- 介面尺寸為390×844、430×932、844×390、932×430、768×1024、1024×768、834×1194、1024×1366、1366×768、1920×1080；兩手機直式同時有繁中／英文。`hasTouch` 明確指定能力；這不是實體裝置測試。
- ST4五分鐘滿載必須用 `npm run test:perf`另跑。一般E2E的skip不等於PASS。報告的機器、瀏覽器、frame-time、物件數與重開穩定性以該次`performance.json`為準。
- 候選版只做分支／PR與本機試玩驗證。未授權main合併、正式Pages部署、Production驗收或tag；不得預填這些結果。
